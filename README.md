# DN-Web

Complaints page.

## Requisitos

- Node.js 20
- npm
- DN-Server rodando em `http://localhost:3333`

## Configuracao

```bash
cp .env.example .env
npm install
```

`REACT_APP_API_URL` define a URL da API.

## Execucao

```bash
npm start
```

O app abre em `http://localhost:3000`.

## Build

```bash
npm run build
```
